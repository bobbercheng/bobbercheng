Company overview · Vexorium Technologies Inc.

Low-cost AI agents for formal mathematics and verification

Vexorium builds AI agents that do expert work, starting with domains where every answer can be checked. Our first product is for mathematics: our agent rewrites formal proofs in the Lean 4 proof assistant so they are shorter, cheaper to check and still valid across library versions, and every result is verified by the Lean compiler.

01

The problem

Formal proofs are becoming critical infrastructure, and they are expensive to maintain.

  • Machine-checked proofs now underpin mathematics libraries such as Mathlib, verified cryptography, programming-language semantics and physics formalizations.
  • Proofs written by people or by AI models are often long and slow to check, and they break when the proof assistant or its libraries are upgraded.
  • Cleaning and porting them takes scarce expert time. Unchecked AI output cannot be trusted in this setting.
02

What we build

An agent that refactors Lean 4 proofs and proves every change with the compiler.

  • Shorter proofs: fewer tokens for the same theorem, with the statement unchanged.
  • Cheaper to check: fewer heartbeats, Lean's deterministic measure of checking work.
  • Version-robust: the same proof compiles unchanged on every Lean version it is checked against (all listed versions in the Arena).
  • Low cost by design: our competition agent runs under a fixed API budget per problem (US$3 in the closed track) and can also run on open-weight models on self-hosted GPUs.

04

How it works

Models propose; the compiler decides.

  • An agent harness drives language models with the Lean compiler in the loop.
  • Every candidate is compiled and measured for length, checking cost and compatibility before it is kept. Nothing is accepted on a model's word.
  • Model calls are budgeted per problem.
  • The same harness runs frontier API models or self-hosted open-weight models, so the cost can be chosen per task.

Code, reproduction steps and our technical report will be published after the competition: github.com/bobbercheng/vexorium-lean-refactor.
